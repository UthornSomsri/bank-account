# เลขบัญชีรับโอน + QR พร้อมเพย์

เปิดผ่านเว็บโฮสต์ (GitHub Pages ฯลฯ) ใช้งานได้เลย ไม่ต้องติดตั้งอะไร

- แก้เลขพร้อมเพย์/ชื่อ: ต้นไฟล์ `script.js` (`PROMPTPAY_ID`, `ACCOUNT_NAME`)
- แก้เลขบัญชีธนาคาร: `index.html` (ค่า `data-raw` คือเลขที่ถูกคัดลอก ส่วนข้อความข้างในคือเลขที่แสดง)
- QR สร้างในเครื่องด้วย `vendor/qrcode.js` (MIT) ไม่ส่งข้อมูลไปเว็บอื่น
- ปุ่ม "บันทึกภาพ" บนมือถือจะเปิดหน้าแชร์ ถ้าเครื่องรองรับ
